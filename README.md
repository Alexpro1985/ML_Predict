Как работает код:
1. Загрузка данных
Данные берутся через API Yahoo Finance:
-цены закрытия
-даты торгов

2. Подготовка данных
Дата переводится в числовой формат (ordinal), чтобы модель могла с ней работать.

3. Обучение модели
Используется:
Linear Regression (линейная регрессия)
Модель ищет зависимость:
дата → цена

4. Прогноз
Модель предсказывает цену на заданную будущую дату.

5. Оценка качества
Используется метрика:
R² score (коэффициент объяснённой вариации)

6. Вывод результатов
Для каждого актива показывается:
прогнозируемая цена
“уверенность” модели (R² в %)

8. Прогресс-бар
Добавлен индикатор выполнения, чтобы видеть процесс обработки активов.
